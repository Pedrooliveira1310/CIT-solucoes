CTI ESCUTA — EXECUTAR NO SEU COMPUTADOR

1. Extraia o ZIP inteiro para uma pasta (não execute dentro do ZIP).
2. Instale Python 3.12 ou mais recente e FFmpeg.
3. Abra o iniciador. A primeira execução precisa de internet para instalar dependências.
4. O navegador abre automaticamente. Mantenha a janela do iniciador aberta.

WINDOWS
No Terminal / PowerShell, você pode instalar os pré-requisitos com:
  winget install --id Python.Python.3.12 -e
  winget install --id Gyan.FFmpeg -e
Feche e reabra o terminal após instalar; depois dê dois cliques em INICIAR-WINDOWS.bat.
Se não tiver winget, obtenha Python em python.org e FFmpeg pelo link de builds Windows em ffmpeg.org/download.html; adicione ambos ao PATH.

macOS
Com Homebrew instalado (brew.sh):
  brew install python@3.12 ffmpeg
No Terminal, dentro da pasta extraída:
  python3.12 iniciar.py

LINUX (Debian/Ubuntu)
Instale Python 3.12+ conforme sua distribuição. Em versões que já fornecem esse Python:
  sudo apt install python3 python3-venv ffmpeg
No terminal, dentro da pasta extraída:
  python3 iniciar.py
